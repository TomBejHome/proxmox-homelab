# Proxmox Homelab

Personal homelab environment focused on virtualization, Kubernetes, GitOps and infrastructure automation.

## Overview

This repository contains configuration and infrastructure components used in my personal homelab running on Proxmox VE.

Main focus areas:

* Infrastructure automation
* Kubernetes workloads
* GitOps workflows
* Networking and virtualization
* CI/CD experimentation
* Learning and testing cloud-native technologies
